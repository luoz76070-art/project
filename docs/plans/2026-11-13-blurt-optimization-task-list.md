# MobiCodex 任务清单

定稿：2026-11-14（第 4 版，替换 11-13 第 3 版）。第 3 版的完整内容见 git 历史（e40e3be）。
规模：S ≤ 1 天，M 2–3 天，L ≥ 1 周（单人，不含真机验收）。

## 已定的决定
- **独立 App（11-14）**：只保留电脑这部分，Kelivo 整合版停更。电脑页现在的界面和功能保持不变，不回退。包名沿用 `com.mobilecodex.app`；正式版是否改名到时再定（B3）。
- **手机平时不切换模型**（M1 不做）。只在额度用完时让用户选别的渠道（F6）。
- **CC Desk（C0 结论）**：网关直连 CC Desk 服务端协议，不需要上游 PR。当前服务端只够只读；发消息、审批、停止要等服务端 ≥0.3.3。升级会重启所有会话，待用户决定。C2、C3、W3b 停在这里。
- **Logo**：A1“墨夜琥珀”，即墨色渐变底 #363B46→#101216、米白 M #F5F1EA、琥珀点 #F59E0B。琥珀只当信号色用。
- **分工与模型（11-14）**
  - 改代码和疑难问题优先由 Claude 自己做，其次派 6-astra high。
  - 探索、跑测试、批量机械修改派 gpt-6.1-sol（当前默认渠道）。
  - 写文档派 deepseek-v4.1-flash。
  - 审查一直由 Claude 做。
  - Codex 的默认模型暂时不改。Codex 同时最多 2 个会话。
- **额度用完（11-14）**：派给 Codex 的任务碰到 429 时，Claude 通知用户，由用户选换哪个渠道，不自动切换。
- **发版**：只在用户说“发”时发。安装包和界面包都在 GitHub Release 存档；手机通过更新通道拿到。
- **测试问题**：一律提成 GitHub issue，每天 21:00 复盘、成批修复。仓库公开，issue 里不能出现个人信息。
