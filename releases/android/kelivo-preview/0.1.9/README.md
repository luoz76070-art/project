## 签名与更新方式

GitHub Release 里的 APK 由 GitHub Actions 构建，使用构建机临时生成的调试证书签名，**与已安装的预览版证书不同，不能覆盖安装**，适合全新安装或核对构建。

已安装 MobiCodex 的手机请用「设置 → 应用更新 → 检查更新」。更新通道提供的是同一次构建，用原预览证书（SHA256 `3ffb81f3524a590f469b80476951a22fbc6e441a470b9270079a8c1d452c4a38`）重新签名，包名不变，覆盖升级，数据保留。两份 APK 的 SHA 不同，内容只差签名；具体值见发布记录。

## 本版内容（相对 0.1.8）

- **语音**：转写结果在电脑端缓存 15 分钟，网络中断后可找回；转写失败保留录音可重转；整理稿丢了数字、路径或否定词时提醒并推荐原文；识别时参考项目名、会话标题等热词；转写文字可在手机上保留 30 天（不存录音，可关闭）。
- **状态**：四个通道统一显示准备中/思考中/执行中/等待/完成/失败/中断，每轮结束显示结果；只保留输入框上方一条状态栏。
- **事项**：新增「事项」页（待处理/进行中/待验证/完成/退回）；可把一件事连同图片和备注交给任意 Agent，确认一次，结果不明不重发；送达、回合完成、失败会自动回写进度；完成或退回 30 天后清理附图、保留文字。
- **界面**：A1 配色与统一的圆角、间距、字号；消息与审批卡重做（危险命令标红、文件改动显示红绿差异）；设置页以连接状态卡开头，高级选项折叠，去掉技术术语；顶栏精简为一行，点标题切换 Agent，列表下拉刷新；胶囊输入框、语音优先；Agent 选择页显示在线状态、会话数和最近活动；骨架屏、品牌空状态、过渡动效和发送/审批轻触感（可关闭）。
- **品牌**：A1 图标（自适应前景/背景/单色层、启动页、通知小图标），启动图标资源改名以刷新桌面缓存；可见文字去掉 Kelivo，开源许可与归属保留。
- **连接**：修复新手机配对时被误判为未授权的问题；被撤销设备的实时连接立即断开；令牌错误时的提示不再只说“已被撤销”。

## 电脑端

事项、交接、进度回写和附图清理需要新版电脑网关；本机已于 2026-11-14 切换到 `2026-11-14-p1-ui-5005e029e9a8`，旧版本与配置备份保留可回退。DeepSeek 原桥接 0.2.7 与 Claude 插件未变；DeepSeek 的每轮结果与活动信息需后续升级桥接后才显示。
