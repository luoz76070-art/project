# MobiCodex 0.2.0（独立 App，versionCode 40）

2026-11-14 · Android 6.0+ · 包名 `com.mobilecodex.app`

## 这一版

MobiCodex 改为独立 App，只保留电脑这部分，不再和 Kelivo 的 AI 聊天打包；Kelivo 整合版（0.1.x，包名 `com.mobilecodex.kelivo.preview`）停止更新。

- **界面与功能不变**：电脑页与 Kelivo 0.1.11 中的同一套页面和样式。配色默认跟随系统取色（与 Kelivo 默认开启的动态取色同一算法），关掉后为 MobiCodex 墨色主题；两种在浅色与深色下都与 Kelivo 下发的配色逐项一致，模拟器上与 Kelivo 版逐页截图逐像素对比一致。唯一的区别是没有底部的「AI / 电脑 / 设置」导航。
- **外观设置**：主题、跟随系统取色、聊天字号、工具卡片与工具结果摘要，在「设置 → 外观与触感」。
- **返回键**：依次关闭事项页、设置、线程抽屉，最后把 App 退到后台。
- **界面更新**：只改界面的更新在后台下载并校验，下次打开时生效；新界面若没能正常启动会自动退回。「设置 → 应用更新」可查看、立即生效或退回上一版界面。
- **语音**：最长 10 分钟，约每 30 秒在停顿处切一段，边录边转文字；切到后台或来电时保留已录内容。
- 修复：线程抽屉在未连接时被长提示撑宽。

电脑端网关与插件无需更新。

## 安装

1. 用下载页的安装包安装（旧版 Mobile Codex 1.x 会直接覆盖升级）。
2. 从 Kelivo 整合版换过来：两者是不同的应用，可同时安装。在电脑上运行 `pair` 生成配对信息，在新 App「设置」粘贴，配对一次；确认正常后再卸载 Kelivo 版。Kelivo 里的 AI 聊天记录和手机上的语音转写记录不会迁移。
3. 以后在「设置 → 应用更新」检查更新。
