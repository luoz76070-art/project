# 设计

当前cc1没有显式inferenceModels，启用发现；接口/v1/models返回14个模型，含连字符和点号两种ID。桌面菜单与该列表逐项对应，不是手机重复登记。

官方桌面第三方配置支持modelDiscoveryEnabled和inferenceModels；指定规范列表并关闭自动发现。先备份当前profile/元数据与native配置，再通过官方配置入口应用，保留密钥格式与非模型字段。Sonnet5.5为既有成功默认；Opus5.5规范ID仅短请求200，须明确完整Code会话尚未单独验证；失败Haiku与点号名称不展示。

只读配置/模型列表与最小真实生成探测分别记证据。没有产品源码变动，仅核对配置差异、桌面菜单、原桥接及文档。
