## 1.2.2-update-restore · 2026-10-20

Android versionCode：**18**。本次保存插件化开发前的源码基线，包含工程重构、实时连接、会话正确性、运行状态、手机界面与在线更新修复。主支持路径为 **macOS + Codex Desktop + Android**；Windows 代码保留，仍需实机验收。

### 用户可见功能

- 手机通过自建 HTTPS Broker 远程查看电脑 Codex 会话，不要求手机与电脑位于同一局域网。
- 按项目分组、搜索和选择会话，查看最近消息、向前加载历史，保留选中会话、草稿和阅读位置。
- 向选中的 Desktop 会话发送文字和附件；默认聊天区显示用户输入和助手正文，隐藏内部上下文及工具参数。
- 根据真实 turn 生命周期与粗粒度工具事件显示思考、工作、输出和结束，重新打开正在运行的会话时恢复状态；助手发出一段文字不再被误判为任务结束。
- 采用 Codex 手机版参考界面，提供浅色、深色及跟随系统主题，优化抽屉、输入栏、代码块、安全区与大字号布局。
- 支持一次性手机配对、独立设备凭证和撤销；Android 原生凭证使用 Keystore 加密，网页端保留原存储方式。
- 设置页提供 APK 更新检查和前端热更新；具名 APK 构建要求同时配置两个更新源，避免产生无法继续在线更新的交付包。

### 实时性与连接恢复

- 公网 Tunnel 按响应头和有界数据块转发 SSE，首块可在响应结束前到达手机，修复完整响应缓冲导致的实时输出延迟。
- 新增 ACK、背压、取消、并发限制和连接代次校验；旧连接及其他 Relay 的回包不能完成当前请求。
- Mac 与 Broker 主动心跳并在失活后退避重连。手机在断流、网络恢复或回到前台时重新获取流令牌并恢复订阅。
- 正常 SSE 工作期间暂停业务轮询；缓存写入合并，会话列表使用增量索引、文件头缓存和低频对账。
- 手机进入后台会关闭实时订阅，回前台恢复；当前不承诺 Android 锁屏后台永久保持连接。

### 数据与输入修复

- JSONL 按完整 UTF-8 字节记录推进游标，覆盖半行、长记录、截断和文件轮换；历史分页保持稳定消息 ID。
- 连接档案、缓存、草稿和在途请求按连接作用域隔离，避免切换设备后读写旧连接。
- 初始化采用共享 Promise 和连接生命周期校验，防止并发初始化及已停止客户端复活。
- Mac 输入事务全进程串行，并使用每次请求独立的临时目录；输入结果未知时禁止自动换通道重发。
- 发送增加有界幂等记录，避免同进程内相同请求重复执行；不保证跨进程重启的 exactly-once。
- 辅助功能授权说明同时覆盖当前 Relay 与 Input，记录旧工程副本、签名和系统权限责任归属的排查方式。

### 更新与维护

- 修复 APK 16/17 构建时遗漏更新源的问题。缺源旧包需先从用户自己的分发入口覆盖安装一次，后续可在 App 内检查更新。
- APK 与热更新共用原子发布流程：校验 SHA-256 和大小、发布锁、不可变产物名称，最后切换清单并保留回退指针。
- 原生热更新校验版本名称、目录包含关系、符号链接及清理边界；限制保留版本数量。
- Mac Relay 增加子进程监督、异常退避恢复、唤醒探测及日志权限和轮转；登录自启仍由用户主动启用。
- 依赖按运行时与构建期归类并升级；生成协议与人工维护源码继续分开。

### 工程布局

- `apps/mobile/src` 按 `app`、`features` 和 `shared` 拆分。
- `apps/relay/src` 按 `server`、`transport`、`store`、`desktop` 和 `codex` 拆分；Node 与 Windows SEA 共用服务工厂。
- 保留现有启动、Mac 打包、Android 构建和 Broker/Tunnel 入口。
- 新增 Trellis 包级规范、任务、审核记录和隔离回归；公开源码不包含 APK、Mac App、本地配置、凭证或原始日志。

### 使用与限制

- 当前 macOS 发送仍依赖 Relay / Input 的辅助功能授权；连接和读取会话不等同于已取得输入权限。
- Mac App 由源码构建，含本机路径，不是可直接复制给其他电脑的便携发行包。
- 电脑关机、离线或睡眠期间不能保证即时执行；长期稳定性测试尚未启动。
- 附件仍采用受并发限制的 base64 JSON 上传，尚未实现文件流式上传。
- 插件安装、移除模拟输入及多 Agent 接入属于下一阶段，本版本尚未交付这些能力。
