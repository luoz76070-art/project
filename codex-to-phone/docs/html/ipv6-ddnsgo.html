IPv6 + DDNSGo 配置

适合电脑有公网 IPv6，且 DDNSGo 已能自动更新域名 AAAA 记录。

  1. DDNSGo 中配置域名 AAAA，例如 example.your-domain.com。
  2. Relay Host 填 ::。
  3. 点击“启动 Relay”。
  4. 点击“测试 IPv6 本机”。
  5. 点击“测试 DDNS 域名”。
  6. 手机关闭 Wi-Fi，仅用流量访问：
http://你的域名:8787/health

如果电脑本机测试成功但手机流量超时，通常是 Windows 防火墙、光猫/路由器 IPv6 防火墙或运营商入站策略拦截。
