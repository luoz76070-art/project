# UI 与交互规范

更新时间：2026-10-23

## 紧凑运行中输入区（APK32）

运行状态和普通发送反馈位于输入框底栏，移除外部重复停止、全宽双按钮与常驻说明。空草稿只显示停止主按钮；有文本/附件时同一底栏显示44px以上的停止、语音、“引导”“排队”，两者直接发送，快捷键默认排队。重要错误/待确认/断线提示仍独立可见。

待发默认仅展示数量与状态，点开保留逐条全文及取消；摘要优先显示结果未知/暂停/正在提交，不能因收起误报“等待执行”。本轮390px运行态footer从271.5px降至125px，真实触摸与键盘另验。见[交付记录](audits/2026-10-23/compact-running-composer.md)。

## 输入区与运行中发送（APK28）

语音入口为发送按钮旁的独立麦克风按钮，44×44px。最新消息位于输入区上方，跟随通知、多行草稿和待发列表的实际高度；点击只跳转正文，不打开语音。其他Agent共用相同语音入口布局。

Codex任务运行中可选“引导当前任务”或“排队，结束后执行”，默认排队；空闲普通发送保持原行为。手机待发由Mac网关保存，可展开查看、取消，离开页面仍等待。当前任务正常完成后在原会话依次执行；中断或失败暂停待发。发送中或结果未知不重复派发，也不能显示为已经撤回。此队列独立于桌面原生队列，不显示在桌面待发列表；详见[交付记录](audits/2026-10-23/composer-queue.md)。

## 执行过程与最终回复（APK30）

Codex明确commentary及已知工具记录运行时展开；同任务明确final_answer开始输出时，自动收起为“执行过程 · N条记录”，最终回复正文独立可见。DeepSeek实时及历史依据原生成功turn结束、无工具末步识别终稿，流结束或空闲不算完成。折叠入口至少44px，点击可重新展开、查看及复制，后续流更新保持手动选择，新任务重新默认展开。没有终稿的中断/失败/断流保留过程；未知阶段旧记录维持可见。用户输入、提问、权限卡均独立于过程区，语音/引导/排队/停止控件保持各自点击区域。只改变显示，不删除内容或改变发送/排队行为。APK30、配套网关及DeepSeek插件0.2.1已发布/加载，详见[验收记录](audits/2026-10-23/process-collapse.md)，Android真机另验。

## 近期会话与项目折叠（APK23）

Codex和DeepSeek均默认显示近30天有活动的会话，提供“查看更早会话/只看近30天”。按cwd/directory完整路径区分项目，显示末级文件夹名，同名目录补充路径，无目录显示“未分类项目”。项目标题含箭头、文件夹与当前已加载会话数，点击区域至少44px；默认展开，展开/折叠偏好按连接和Agent隔离保存，刷新/分页不重置，搜索临时展开。顶部窄窗支持整体滚动到项目入口，左侧窄栏保留箭头与名称。

仅列表前台每30秒及回前台刷新摘要，桌面新会话或旧会话的新活动在下次刷新进入；正文打开时按需读取。保留当前查看/运行中/待确认项，普通已读缓存不把所有旧会话留在近期列表。行为与浏览器证据见[交付记录](audits/2026-10-22/project-groups.md)，原生安装及前后台仍须真机验收。

## 设计目标

手机端的主要视觉与交互参考改为 Codex 手机版，优先让用户快速找到线程、阅读输出、继续任务。桌面能力按手机屏幕和单手操作习惯收纳，保持轻量、实时、随时可重新接入。

实施前需选定可核验的 Codex 手机版版本，记录平台、版本或采集日期，整理线程列表、聊天、输入栏、设置及浅深主题的参考画面，并形成组件对照。本轮尚未采集真实参考画面，下文是本项目的设计要求，不代表已核实官方当前界面或完成视觉还原。具体配色、字号、间距、圆角和图标以该对照基线确定。

## 核心原则

- 主界面优先呈现工作，不优先呈现配置。
- 连接诊断放入设置面板。
- 窄屏以聊天为主，线程通过抽屉进入；宽屏保留线程列表与聊天分屏。
- 工具输出、审批、diff 是开发界面的一等公民。
- 所有动态内容不能造成布局跳动。
- 长文本、长命令输出、长路径必须可滚动或折叠，不能撑爆屏幕。
- 白天和黑夜主题都必须独立打磨，不只是反色。
- 默认只展示当前任务必需信息，完整路径、来源、threadId 等信息按需展开。
- 优先复用现有 React、CSS 和图标资源，不为视觉对齐新增大型组件库、动画库或完整图标包。

## Codex 手机版对照范围

| 区域 | 对照与落地要求 |
| --- | --- |
| 线程入口与列表 | 对照导航层级、选中态、搜索与新建入口；保留项目分组和最近线程，切换后收起窄屏抽屉 |
| 聊天区 | 对照用户与助手消息层级、行宽、留白、Markdown 和代码展示；长工具输出默认折叠 |
| 底部输入栏 | 对照输入框、附件、发送/停止操作的布局；适配键盘、安全区、多行草稿和单手触达 |
| 运行与连接状态 | 将任务运行状态与网络连接状态分别呈现；恢复连接时保留消息和草稿，鉴权失败提供重新配对入口 |
| 设置与配对 | 设置收纳连接档案、主题、配对和诊断；已配对用户默认直接进入工作区 |
| 主题与反馈 | 对照浅深主题、图标、按压和过渡反馈；遵循减少动态效果设置，优先保证流式阅读稳定 |

功能按钮按当前连接的真实能力显示。Desktop 与 Relay 的审批、中断能力需分别验收，不能通过界面相似暗示尚未打通的控制能力。

## 布局

### 竖屏手机

默认形态：

```text
Top Bar
  当前项目 / 当前线程 / 状态

Main
  Chat Detail

Bottom
  Composer
```

会话列表：

- 从左侧滑出。
- 顶部按钮打开。
- 选择线程后自动收起。
- 保留桌面端“左列表、右内容”的心智模型。
- 用户可以切换为顶部固定线程栏，适合折叠屏竖向分屏。
- 用户可以强制左侧固定，适合折叠屏展开态、平板和横屏。
- 用户可以强制抽屉，适合小屏单手使用。

### 横屏手机 / 折叠屏 / 平板

使用真实分屏：

```text
┌───────────────┬────────────────────────┐
│ Thread List   │ Chat Detail            │
│ Search        │ Messages               │
│ Projects      │ Tool Output / Approval │
│ Recent        │ Composer               │
└───────────────┴────────────────────────┘
```

### 分屏模式

必须提供四种模式：

- 自动：宽屏左侧固定，窄屏抽屉。
- 左侧：线程列表固定在左侧，聊天区在右侧。
- 顶部：线程列表固定在顶部，聊天区在下方。
- 抽屉：线程列表隐藏，需要时滑出。

模式必须本地保存，下次打开保持。

分屏细则：

- 左侧模式必须有中间分隔线，支持长按/拖动调整左右宽度。
- 顶部模式必须是上下分屏：上方线程列表、下方聊天区，线程列表纵向浏览，不能做成横向找窗口。
- 顶部模式必须有中间分隔线，支持长按/拖动调整上下高度。
- 左右/上下分屏尺寸必须本地保存，下次打开保持。
- 分隔线拖动必须设置最小聊天区尺寸，不能把聊天区、消息列表或输入框挤没。
- 抽屉模式关闭时不能占用主网格空间，切回聊天后必须显示完整聊天窗口。
- 任意模式切换后，当前聊天窗口必须保持可用：标题、消息区、输入区和发送按钮都不能残缺或被侧栏遮住。
- 窄屏强制左侧模式时，线程栏进入紧凑形态，只保留必要标题，优先保证聊天区完整。

### 桌面预览

Web preview 应接近平板分屏，方便开发时用浏览器验证 UI。

## 主题

### 白天主题

- 背景：中性浅色，减少装饰层次，具体色值由参考基线确定。
- 面板：以不透明或低透明度底色保持阅读清晰。
- 边框：低对比细描边或留白分区。
- 主色：按参考基线统一，用于必要操作与选中态。
- 成功：低饱和绿色。
- 警告：琥珀色。
- 危险：柔和红色。

### 黑夜主题

- 背景：中性深色，具体层次由参考基线确定。
- 面板：以稳定底色区分层级，避免大面积实时模糊。
- 边框：低对比描边，避免光晕。
- 文本：主文本高对比，次级文本降低透明度。
- 主色：与白天主题语义一致，不使用装饰性发光。
- 工具输出：接近终端深色块。

### 主题行为

必须支持：

- 跟随系统。
- 手动白天。
- 手动黑夜。
- 用户选择保存在本地。

## 组件规范

### Top Bar

内容：

- 左侧：侧栏按钮或返回按钮。
- 中间：当前线程名，必要时显示简短状态。
- 右侧：保留必要操作，其余进入菜单；完整 cwd 与诊断放入详情或设置。

要求：

- 固定顶部。
- 使用清晰底色，按参考基线确定是否需要局部轻微透明。
- 滚动时保持清晰。

### Thread Sidebar

内容：

- 搜索框。
- 项目/线程分组。
- 最近线程列表。
- 连接状态小点。

Thread Row 默认显示：

- 线程标题。
- 最新摘要。
- 更新时间。
- 必要状态：运行中、等待审批、失败。
- 完整项目路径、来源标签和完成详情在展开或菜单中查看，避免每行堆满元数据。

交互：

- 点击打开。
- 长按弹出：复制标题、复制路径、收藏、刷新。
- 当前选中项使用参考基线确定的浅底色或边线，保持文字清晰。

### Chat Detail

要求：

- 首次打开线程定位到最新消息；返回已浏览线程优先恢复阅读位置。
- 用户上拉后进入“浏览历史模式”。
- 浏览历史时新消息不强制拉到底部，而是显示悬浮提示。
- 点击“最新”回到底部。
- 消息宽度、间距与用户/助手视觉层级按 Codex 手机版对照基线确定。
- 线程切换优先即时展示缓存，短暂过渡不得延迟内容出现。
- 每个连接档案、每个线程保留独立草稿，切回来时不丢也不串线。
- 每个线程发送状态独立，允许一个线程发送中时查看另一个线程。

线程定位信息：

- 聊天详情按需显示来源、cwd，顶栏保持简洁。
- 可复制 threadId、cwd、rolloutPath。
- 对手机新建线程显示“手机线程，电脑端可能需要刷新或按路径查找”的状态提示。

消息类型：

- User：按参考基线确定对齐与背景，清晰区分用户输入。
- Assistant：以正文阅读为主，按参考基线确定排版。
- Tool：全宽可折叠块。
- System/Rule：低视觉权重。
- Approval：高权重操作卡片。

### Composer

内容：

- 多行输入框。
- 发送按钮。
- 附加按钮。
- 中断按钮。
- 当前模式提示：当前线程 / 新线程 / 等待审批。

交互：

- 输入时自动增高但有最大高度。
- 发送后保持焦点。
- 长文本发送前不改变布局。
- 当前通道支持时，发送中可中断；不可用时明确展示原因。
- 键盘弹出、收起和安全区变化时，输入框及发送/停止按钮始终可见。
- 断线时保留草稿与发送确认状态；状态不明时先核对结果，避免用户重试导致重复提交。

### Tool Output Card

显示：

- 命令。
- cwd。
- 状态。
- 耗时。
- exit code。
- stdout/stderr。

交互：

- 默认折叠长输出。
- 可展开。
- 可复制命令。
- 可复制输出。
- 失败状态明显但不过度刺眼。

### Approval Sheet

显示：

- 请求类型。
- 命令或文件变更。
- cwd。
- 风险说明。
- diff 摘要。

操作：

- 允许。
- 拒绝。
- 查看详情。
- 危险操作二次确认。

## 动效

按需实现短暂反馈：

- 侧栏滑入滑出。
- 线程切换可使用短淡入，优先即时展示缓存。
- 新消息按批次渲染增量，不为每个字符单独创建动画。
- 正在执行状态使用静态提示或低成本进度反馈。
- 主题切换平滑过渡。
- 底部输入区跟随键盘稳定调整。
- 分屏模式切换动画。
- 按钮 press 反馈，桌面预览按需增加 hover。

遵循 `prefers-reduced-motion`，页面不可见时停止装饰动画。不以新增业务轮询驱动界面状态，不要求持续脉冲、大面积模糊或多层玻璃效果。

不做：

- 夸张弹跳。
- 大面积彩色渐变动画。
- 装饰性光球背景。
- 营销页式 hero。

## 可访问性

要求：

- 触控目标不小于 44px。
- 长路径可横向或中间截断。
- 小屏文字不重叠。
- 支持系统字体缩放的基本可用性。
- 黑夜模式对比度足够。

## 用户选择卡片（源码已实现，待真实验收）

- 方案选择/追问在聊天区使用独立卡片，不随普通工具日志隐藏；线程状态显示“等待你选择”。
- 展示题目、选项、选项说明和协议支持的补充输入，多问题可逐题填写；保持 Codex 手机版的简洁排版。
- 底部明确提交；预选不等于提交。只在原请求支持时展示跳过/取消，不能编造动作。
- 提交中禁用重复操作；成功、桌面已处理、失效/中断和结果待确认分别呈现。切换档案不能串题或串答案。
- 键盘弹出后关键按钮仍可达；沿用 44px 触控目标和小屏无溢出约束。敏感回答不写入普通持久缓存。
- 普通问题与操作审批区分文案和行为，不能用“允许一次”回答选择题。没有可验证回复通道时不显示可用提交按钮。
- 原生发送与中断各自显示待确认提示；中断ACK后仍保留真实工作状态。桌面确认或任务自然结束才更新终态，迟到HTTP不能重新点亮运行状态。重连/重新打开时从原生回执恢复待确认提示，避免用户重复提交。

## UI 验收标准

- 线程列表、聊天、输入栏、设置及浅深主题均有真实参考画面对照，并标注为适配本项目而保留的差异。
- 首页第一屏以当前聊天为中心，诊断在设置中查看。
- 手机竖屏可快速打开会话列表并切换线程。
- 横屏和平板有真正左右分屏。
- 首次打开线程显示最新内容，返回线程恢复阅读位置与草稿。
- 上拉历史不会被新消息打断。
- 白天黑夜主题都能长时间使用。
- 所有连接错误都能解释，但不抢占主界面。
- 360、390、430 CSS px 宽度均无页面横向溢出；代码块允许内部滚动；横屏、键盘弹出/收起、安全区及系统字体缩放后关键操作仍可达。
- 流式长文本、代码、工具输出、历史分页、断流恢复与切连接档案均不跳动、不丢草稿、不串消息。
- UI 改造前后对比构建体积、缓存首屏、增量渲染延迟和滚动表现；沿用审核报告的性能门槛，新增体积需说明来源与必要性。

### Desktop 审批卡片

2026-10-21源码新增：原会话命令、文件和权限请求独立于选择题。展示命令、目录、理由、完整文件差异或权限范围，详情默认展开。只渲染原请求可用的决定；复杂策略和未知范围显示电脑处理入口说明，不能凭空增加允许按钮。按钮至少44px，卡片区可滚动。

提交中、已提交等待同步、结果待确认均保留卡片并禁用按钮；ACK不能显示为已批准。权威请求消失时移除（已处理或失效）；不把自然结束认作本次决定生效。断流废止Desktop卡片，重连等新快照，同一未确认请求仍锁定；卡片/权限对象/令牌不持久化。迟到HTTP不能恢复旧卡片、影响替换卡片或改变任务终态。生产APK尚未包含本轮功能。

### 插件配对与连接能力
