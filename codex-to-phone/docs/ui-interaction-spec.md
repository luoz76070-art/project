# UI 与交互规范

更新时间：2026-05-12

## 设计目标

把手机端做成 Codex Desktop 的移动工作台，而不是连接工具页。视觉方向是 iOS 26 / Liquid Glass 风格：清透、分层、柔和反射、白天黑夜两套主题，同时保持开发工具的高信息密度。

## 核心原则

- 主界面优先呈现工作，不优先呈现配置。
- 连接诊断放入设置面板。
- 使用分屏/抽屉模拟桌面端左侧会话列表 + 右侧聊天详情。
- 工具输出、审批、diff 是开发界面的一等公民。
- 所有动态内容不能造成布局跳动。
- 长文本、长命令输出、长路径必须可滚动或折叠，不能撑爆屏幕。
- 白天和黑夜主题都必须独立打磨，不只是反色。

## 布局

### 竖屏手机

默认形态：

```text
Top Bar
  当前项目 / 当前线程 / 状态

Main
  Chat Detail

Bottom
  Composer
```

会话列表：

- 从左侧滑出。
- 顶部按钮打开。
- 选择线程后自动收起。
- 保留桌面端“左列表、右内容”的心智模型。
- 用户可以切换为顶部固定线程栏，适合折叠屏竖向分屏。
- 用户可以强制左侧固定，适合折叠屏展开态、平板和横屏。
- 用户可以强制抽屉，适合小屏单手使用。

### 横屏手机 / 折叠屏 / 平板

使用真实分屏：

```text
┌───────────────┬────────────────────────┐
│ Thread List   │ Chat Detail            │
│ Search        │ Messages               │
│ Projects      │ Tool Output / Approval │
│ Recent        │ Composer               │
└───────────────┴────────────────────────┘
```

### 分屏模式

必须提供四种模式：

- 自动：宽屏左侧固定，窄屏抽屉。
- 左侧：线程列表固定在左侧，聊天区在右侧。
- 顶部：线程列表固定在顶部，聊天区在下方。
- 抽屉：线程列表隐藏，需要时滑出。

模式必须本地保存，下次打开保持。

分屏细则：

- 左侧模式必须有中间分隔线，支持长按/拖动调整左右宽度。
- 顶部模式必须是上下分屏：上方线程列表、下方聊天区，线程列表纵向浏览，不能做成横向找窗口。
- 顶部模式必须有中间分隔线，支持长按/拖动调整上下高度。
- 左右/上下分屏尺寸必须本地保存，下次打开保持。
- 分隔线拖动必须设置最小聊天区尺寸，不能把聊天区、消息列表或输入框挤没。
- 抽屉模式关闭时不能占用主网格空间，切回聊天后必须显示完整聊天窗口。
- 任意模式切换后，当前聊天窗口必须保持可用：标题、消息区、输入区和发送按钮都不能残缺或被侧栏遮住。
- 窄屏强制左侧模式时，线程栏进入紧凑形态，只保留必要标题，优先保证聊天区完整。

### 桌面预览

Web preview 应接近平板分屏，方便开发时用浏览器验证 UI。

## 主题

### 白天主题

- 背景：浅色冷白、轻微蓝绿层次。
- 面板：高透明白玻璃。
- 边框：白色高光 + 极浅蓝灰描边。
- 主色：克制蓝色，用于选中、发送、状态。
- 成功：低饱和绿色。
- 警告：琥珀色。
- 危险：柔和红色。

### 黑夜主题

- 背景：深灰黑，不使用大面积纯黑。
- 面板：深色半透明玻璃。
- 边框：低透明白色描边。
- 文本：主文本高对比，次级文本降低透明度。
- 主色：蓝青色发光但不过度霓虹。
- 工具输出：接近终端深色块。

### 主题行为

必须支持：

- 跟随系统。
- 手动白天。
- 手动黑夜。
- 用户选择保存在本地。

## 组件规范

### Top Bar

内容：

- 左侧：侧栏按钮或返回按钮。
- 中间：当前线程名，下面一行是 cwd 或状态。
- 右侧：搜索、刷新、设置。

要求：

- 固定顶部。
- 半透明毛玻璃。
- 滚动时保持清晰。

### Thread Sidebar

内容：

- 搜索框。
- 项目/线程分组。
- 最近线程列表。
- 连接状态小点。

Thread Row 显示：

- 线程标题。
- 最新摘要。
- 更新时间。
- 项目路径尾部。
- 来源标签：桌面、手机、CLI、未知。
- 状态：运行中、等待审批、失败、完成。

交互：

- 点击打开。
- 长按弹出：复制标题、复制路径、收藏、刷新。
- 当前选中项有玻璃高亮，不用大色块。

### Chat Detail

要求：

- 打开线程后自动滚动到底部。
- 用户上拉后进入“浏览历史模式”。
- 浏览历史时新消息不强制拉到底部，而是显示悬浮提示。
- 点击“最新”回到底部。
- 消息宽度和间距接近开发工具，不做社交聊天泡泡过度圆润。
- 线程切换需要淡入/位移动效。
- 每个线程保留独立草稿，切回来时不丢。
- 每个线程发送状态独立，允许一个线程发送中时查看另一个线程。

线程定位信息：

- 聊天标题区显示来源、cwd。
- 可复制 threadId、cwd、rolloutPath。
- 对手机新建线程显示“手机线程，电脑端可能需要刷新或按路径查找”的状态提示。

消息类型：

- User：右侧或强调边线。
- Assistant：左侧主体内容。
- Tool：全宽可折叠块。
- System/Rule：低视觉权重。
- Approval：高权重操作卡片。

### Composer

内容：

- 多行输入框。
- 发送按钮。
- 附加按钮。
- 中断按钮。
- 当前模式提示：当前线程 / 新线程 / 等待审批。

交互：

- 输入时自动增高但有最大高度。
- 发送后保持焦点。
- 长文本发送前不改变布局。
- 发送中可中断。

### Tool Output Card

显示：

- 命令。
- cwd。
- 状态。
- 耗时。
- exit code。
- stdout/stderr。

交互：

- 默认折叠长输出。
- 可展开。
- 可复制命令。
- 可复制输出。
- 失败状态明显但不过度刺眼。

### Approval Sheet

显示：

- 请求类型。
- 命令或文件变更。
- cwd。
- 风险说明。
- diff 摘要。

操作：

- 允许。
- 拒绝。
- 查看详情。
- 危险操作二次确认。

## 动效

需要实现：

- 侧栏滑入滑出。
- 线程切换淡入。
- 新消息流式出现。
- 正在执行状态脉冲或细进度线。
- 主题切换平滑过渡。
- 底部输入区跟随键盘稳定调整。
- 分屏模式切换动画。
- 玻璃面板 hover/press 反馈。

不做：

- 夸张弹跳。
- 大面积彩色渐变动画。
- 装饰性光球背景。
- 营销页式 hero。

## 可访问性

要求：

- 触控目标不小于 44px。
- 长路径可横向或中间截断。
- 小屏文字不重叠。
- 支持系统字体缩放的基本可用性。
- 黑夜模式对比度足够。

## UI 验收标准

- 首页第一屏看起来像开发工作台，而不是诊断页。
- 手机竖屏可快速打开会话列表并切换线程。
- 横屏和平板有真正左右分屏。
- 打开线程自动在底部。
- 上拉历史不会被新消息打断。
- 白天黑夜主题都能长时间使用。
- 所有连接错误都能解释，但不抢占主界面。
