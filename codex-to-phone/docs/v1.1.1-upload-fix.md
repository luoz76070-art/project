# v1.1.1-upload-fix 修复记录

更新时间：2026-05-13

## 修复原因

`v1.1-upload` APK 能构建成功，但 Android 工程缺少 Capacitor 启动入口：

```text
com.mobilecodex.app.MainActivity
```

所以手机安装后点击图标会打不开或闪退。

## 修复内容

- 新增 `MainActivity.java`，继承 Capacitor `BridgeActivity`。
- APK 版本升级为 `1.1.1-upload-fix`，`versionCode=3`。
- 打包脚本支持传入版本号，避免后续再写死 APK 文件名。
- 重新生成独立 Windows 包，不覆盖 `v1.1-upload`。

## 应安装的版本

请安装：

```text
安装文件-v1.1.1-upload-fix\apk\mobile-codex-1.1.1-upload-fix-debug.apk
```

不要再安装：

```text
安装文件-v1.1-upload\apk\mobile-codex-1.1-upload-debug.apk
```

## 验证

- TypeScript 检查通过。
- APK 构建成功。
- `aapt dump badging` 已确认存在启动入口：

```text
launchable-activity: name='com.mobilecodex.app.MainActivity'
```

- `apksigner verify --verbose` 已通过 v1/v2 签名验证。
- Windows 独立包 `/health` 烟测通过。
