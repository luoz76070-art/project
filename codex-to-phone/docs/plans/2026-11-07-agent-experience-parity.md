# 电脑 Agent 通道统一体验

状态：2026-11-07 用户已要求将当前 Codex 界面、功能和交互同步到 DeepSeek Harness，并明确确认现有 Claude Code、OpenCode 及以后新增的电脑 Agent 通道也统一复用。本计划承接已真机通过的 code8；完整 Kelivo 59 组验收继续独立记录。

## 本轮目标与验收

1. 共用输入区与消息展示：沿用 code8 的主题、字号、头像/时间、说明常显、连续工具动态摘要、一次展开、终稿独立和工具显示偏好。Codex 与其他 Agent 使用同一个输入组件，保留文本/附件、语音、发送、运行中引导/排队/停止、未知提交保护。各操作仍由实际通道控制能力决定，不以视觉统一扩大权限。
2. DeepSeek 原进程传出可展示的工具调用与输出，保留原 turn/step、稳定身份与成功完成边界；实时与按需历史一致，推理和私有错误不投影。Claude/OpenCode 按其已验证原接口同步可用的工具记录，未知内容明确保持未适配，不伪造执行结果。
3. 所有 SessionAdapter 通道共用鉴权图片接口与大图/原尺寸/重试。项目目录只从当前设备已订阅的原会话快照取得，不接受手机指定根目录；沿用8MiB、格式/真实路径校验及有界并发。断线、撤销或关闭订阅后不可继续借旧会话读取。
4. 附件沿原上传接口与消息附件格式发送；草稿按连接/Agent/会话隔离，上传/存储失败阻止离开，确认只清对应提交，未知不重发。无需调用手机AI路由任务。
5. 后续通道通过显式 SessionAdapter 能力登记自动进入共享工作区；新增通道不得复制聊天/图片/输入实现。加入跨通道隔离回归、窄屏/深色/150%字号与核心按钮实际浏览器验证。
6. 相关检查通过后递增预览版本，同步源码/APK到现有GitHub及独立App更新源，保留previous与原通道；电脑网关/插件交付和实际宿主加载、真机验收分开记录。

## 最小改动边界与所有者

- `features/chat` 提供共用输入组件、上传与图片上下文，`AgentWorkspace` 只接线原控制和草稿，不复制 Codex 运行态算法。
- `agentSessionRoutes` 在现有订阅生命周期内绑定设备/Agent/会话的权威目录，复用 `readThreadImage` 的文件读取策略；SessionAdapter 仍拥有会话和控制。
- `plugins/mobile-deepseek/messages.mjs` 拥有原事件显示投影，bridge/catalog 复用；交互审批的完整工具索引继续独立，不因显示截断改变允许决定。
- Claude/OpenCode 的已验证协议投影保留各自来源和能力，前端只消费统一 AgentMessage，不从助手文字猜工具调用。
- 测试只用临时目录、合成服务及官方隔离运行时，不读用户会话、不提交真实模型任务。原Desktop新建、其他Kelivo系统能力和DeepSeek旧待验控制项不借本轮宣称完成。
