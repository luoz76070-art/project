# W2a online capture
Approved scope: static JPEG/PNG/WebP uploads, metadata removal without decoding/re-encoding, durable managed asset receipts, controlled CaptureSession creation, undeployed todo capture deletion/tombstones, online web file/voice panel. No dependencies, Android, camera, offline drafts, dispatch or retention jobs.
Acceptance: forged MIME/SVG/animation/oversized dimensions rejected; metadata removed with image bytes unchanged; asset identity conflict 409; authenticated read; CAS and tombstones; raw ASR frozen; 401 stops operations. Existing W1 and uploads remain compatible.
