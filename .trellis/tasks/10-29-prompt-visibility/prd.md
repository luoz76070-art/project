# 阶段三：正常提示词显示

用户要求继续后续计划，本轮按阶段三执行。目标：正常提示词在本地输入、实时消息、历史回放和缓存重开后保留；明确的系统上下文继续隐藏。

验收：`You are a code reviewer. Check this module.`、Knowledge cutoff正文、普通中英文及附件文本可见；真实同文多次发送独立保留；system/developer、hook及旧专用上下文包络不成为用户气泡；问答回执不进入普通聊天/缓存。

边界：只修过滤，不变更消息身份、不解决未经证实的真机双气泡；阶段四诊断与阶段五模块整理待下一轮。仅合成数据、临时目录和隔离浏览器，不发布、不操作真实模型、不做Git写入。
