# Codex 会话同步与发送能力故障排查

## Goal

核对用户报告的手机Codex线程同步不全和有草稿时发送按钮置灰，区分网络、列表范围、桌面会话加载和手机提交状态；只根据已确认的故障实施针对性修复。

## Requirements

- 比较本地和公网鉴权、网关、IPC健康及同一会话的实时控制能力，不能用健康检查通过推断可发送。
- 比较近30天与全部时间的列表，并核对桌面记录来源、更新时间及用户指定的缺失会话。
- 对已加载和未加载会话作只读对照，不向真实模型发送消息、重放未知提交、清缓存或中断业务任务。
- 用户已指定Kelivo样本；修复原会话按需加载，覆盖其他未加载会话。仅当前手机查看触发恢复，列表和后台待发不自动激活。
- 继承原工作区修改；DeepSeek控制验收暂停，其原权限恢复仍为未完成项。

## Acceptance Criteria

- [x] 保存两端健康、列表及逐会话SSE控制能力证据，并给出可证伪的原因判断。
- [x] 关联用户实际异常线程，或明确尚缺的现场信息，不能用代表样本宣称全部故障已解决。
- [x] 若有源码修复，先复现对应时序并作相关隔离回归，真机只读按钮恢复与真实发送分开验收。
- [x] 汇总检查结果、当前可用路径和后续修复范围，注明有无部署、真实消息或权限变更。
