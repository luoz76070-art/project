## 本轮范围：P0 现有服务接入

- 通过 Unix socket 上的 WebSocket（含标准 HTTP Upgrade）直接接入已有服务，不启动替代 app-server 或新模型会话。
- 只执行协议初始化和 `thread/loaded/list`，返回连接状态、已加载会话数量及分页标记；不读取正文、不暴露会话 ID、不发送任务或审批。
- 提供可扩展的 Agent 适配接口、已鉴权的状态 API，以及仅管理员可以触发的按需探测。
- 默认不连接、不新增常驻进程；并发探测共享初始化，停止时只关闭本工具创建的连接，不终止既有 daemon。
- 提供显式人工只读探测入口及完全隔离的合成回归。

## 验收

- GitHub 源码、功能说明、版本标签及本地备份完成在本轮业务代码修改之前。
- 仅允许连接现有 Unix socket；服务不存在、协议不兼容或超时均明确失败，不回退启动其他会话。
- 覆盖 WebSocket 分片、UTF-8、多帧、初始化并发、异常 JSON、缓冲边界、超时、断线、停止期间初始化和重连。
- 状态 API 不自动执行探测；设备凭证可查看状态，只有管理员可触发探测。
- 隔离测试不读取真实 Codex 会话、不启动 Codex、不修改系统权限或自动部署。
- 真实只读握手与真实发送分别记录；握手成功不能标记现有 Desktop 同会话发送已通过。
