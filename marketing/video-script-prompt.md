# Mobile Codex 项目介绍视频稿本提示词

用途：把本提示词交给视频脚本、分镜、AI 视频或剪辑助手，生成一条 2 到 3 分钟的中文项目介绍视频。风格参考 baoyu slide-deck 的产品演示思路：信息密度清楚、节奏干净、每个镜头自解释，适合技术产品发布或公众号配套视频。

## 视频目标

介绍 Mobile Codex / Codex To Phone：一个让 Android 手机远程查看并控制 Mac 上 Codex Desktop 的项目。重点讲清楚它从扫码网页桥接演进到 1.1.11 App 版本，以及当前为什么选择 Mac Relay App + Android App + 公网 Broker 架构。

## 受众

- 正在使用 Codex Desktop 的开发者。
- 想离开电脑后继续掌握 Codex 进展的 AI 工具重度用户。
- 想了解本地 AI 工作流如何做手机远程控制的技术用户。

## 语气

真实、克制、有工程现场感。不要夸大成完美产品。要承认限制：Mac 端依赖辅助功能权限，公网 Broker 需要部署，在线更新仍要 Android 系统确认安装。

## 视频结构

### 片头，0:00-0:12

画面：

- Mac 上 Codex Desktop 正在生成。
- 用户离开电脑，切到手机。
- 手机上显示同一个 Codex 会话的最新输出。

旁白：

“我想解决一个很小但很真实的问题，Codex 在电脑上跑任务的时候，人离开电脑以后，还能不能用手机知道它在干什么，甚至继续给它发指令？”

字幕：

“把 Codex 的当前工作流，延伸到手机上。”

### 痛点，0:12-0:35

画面：

- 电脑上 Codex 跑测试、读文件、写文档。
- 手机上普通聊天机器人无法看到本机上下文。
- 远程桌面画面太重。

旁白：

“我不想做远程桌面，也不想在手机上另开一个影子 Codex。目标只有一个，手机成为当前 Codex Desktop 会话的遥控器。”

屏幕文字：

- 不是远程桌面
- 不是历史聊天归档
- 是当前会话远程控制

### 第一版扫码桥，0:35-0:58

画面：

- 终端启动 bridge。
- 出现二维码。
- 手机扫码打开网页。

旁白：

“第一版是扫码网页，能证明链路可行，但不适合长期使用。二维码依赖临时地址，局域网模式也不满足离开电脑的场景。”

屏幕文字：

“Phase 0：单会话扫码绑定，可验证，不够产品化。”

### 手机输入回到 PC，0:58-1:25

画面：

- 后台 app-server 路线被画成旁路。
- 当前 Codex Desktop 窗口高亮。
- 手机发送消息，Mac 输入框出现文字并提交。

旁白：

“后来发现，后台 app-server 即使能写入同一个 thread，桌面当前窗口也不会显示生成过程。真正要做的是让当前 Codex Desktop 窗口自己发起这一轮。所以 Mac 端改成聚焦 thread，再通过辅助功能提交手机输入。”

屏幕文字：

“关键判断：必须进入 Desktop 当前窗口，而不是旁路运行时。”

### Broker 架构，1:25-1:55

画面：

- 三段结构图：Android App、Public Broker、Mac Relay App。
- 箭头显示 Android 和 Mac 都主动访问公网 Broker。

旁白：

“远程场景下，不应该依赖同一个 Wi-Fi。现在的正式方向是 Broker，Mac Relay 主动连接公网 Broker，Android App 也连 Broker。Broker 只转发，不保存完整会话。”

屏幕文字：

“Android App -> Broker -> Mac Relay -> Codex Desktop”

### 1.1.11 当前体验，1:55-2:30

画面：

- Android App 设置 Endpoint 和 Token。
- 打开会话列表。
- 手机发送一句话。
- Codex 文本结果在手机端平滑出现。
- 附件缩略图、Light/Dark 主题、在线更新状态快速闪过。

旁白：

“到 1.1.11，我做了一个减法。手机端默认只显示用户输入和 Codex 文本结果，隐藏工具调用、命令日志和内部桥接状态。手机不是来审代码 diff 的，它是用来掌握进度和继续控制的。”

屏幕文字：

- 只显示输入与文本结果
- 附件缩略图
- Light / Dark 主题
- 在线更新

### 结尾，2:30-2:55

画面：

- 用户在外面打开手机，看见 Codex 完成回复。
- 回到架构图，最后落到 GitHub README。

旁白：

“这个项目还不是最终形态。它还需要更稳的 Broker 部署、更好的开机自启动、更完整的在线更新和多会话管理。但它已经证明了一件事，Codex 的桌面工作流可以被手机轻量接管，而不是被远程桌面粗暴复制。”

字幕：

“Mobile Codex，手机上的 Codex 远程控制台。”

## 画面风格

- 深色和浅色都要出现，但主基调克制、清爽、工具感强。
- 不做夸张科技感光效，不做营销落地页式大字报。
- 多用真实 UI、简洁架构图、终端命令和手机界面动效。
- 字幕短句，不堆长段解释。

## 输出要求

请生成：

1. 完整旁白稿。
2. 逐镜头分镜表，包含时间、画面、动作、字幕、素材建议。
3. 3 个标题备选。
4. 1 条 30 秒短版剪辑脚本。
